# RO’Lyfe — Plenty More To It

### *But I’d Rather Show You.*

**Plenty More To It** is an interactive digital book created by RO’Lyfe.

This project combines storytelling, education, visual intelligence, tools, resources, affiliate discovery and a future RO’Lyfe ComicVerse into one digital experience.

## Current Focus

The first expansion layer is **RO’Lyfe ComicVerse**.

ComicVerse is designed around:

- Comic discovery
- Character discovery
- Comic collecting
- Graphic novels
- Comic-related collectibles
- Auctions
- Affiliate resources
- Original RO’Lyfe storytelling

The project may reference well-known characters as **third-party discovery categories**, but RO’Lyfe will create its own original characters, stories and artwork rather than copying copyrighted characters or artwork.

## Affiliate Setup

MyComicShop affiliate tracking is centralized in:

`data/links.js`

After obtaining a MyComicShop Affiliate ID, enter it here:

`affiliateId: ""`

Example:

`affiliateId: "YOUR_AFFILIATE_ID"`

Do not place passwords, payment information or private account credentials in this repository.

## Important

The current project does not claim that MyComicShop provides full digital comic reading. It is primarily a marketplace and discovery resource for comics, graphic novels, collectibles and related material.
